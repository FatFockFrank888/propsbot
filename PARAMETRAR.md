# Propsbot – alla parametrar

Genereras från de värden boten använder (`python -m propsbot parametrar`).

## Gemensamt

| Parameter | Värde | Förklaring |
|---|---|---|
| A/B/C Tier | på | Ersätter Official Bets (18/11). Varje bokfört spel (LIVE, regelspel, skuggspel; props och sides; fotboll och NBA) hamnar i den högsta nivå det klarar. Ett spel per spelare och match. Nivåerna rättas var för sig (fliken Tier-resultat). |
| C Tier | edge ≥ 4 %, odds 1,40–6,50 | Edge och statistik talar för spelet. Inga hårda spärrar (skadelista out/doubtful, startelva, orimlig edge, avvikande pris) och inget sharp money mot oss. Edge över 25 % räknas inte. Bara bokföring: visar om kraven för B/A är för skarpa. |
| B Tier | C + edge 5 %–20 %, odds 1,60–6,00 | Fokus på CLV: Pinnacle (eller DraftKings där Pinnacle saknar marknaden) som referens, oddset har inte fallit, ingen annan skarp källa säger emot, Pinnacles gräns räcker, förväntad CLV ≥ 0 där den finns. Spelas, notis. |
| A Tier | B + alla parametrar, odds 1,60–3,50 | NBA: klarar LIVE-kraven (se NBA nedan). Fotboll: klarar alla regler (regelspel). Spelas. |
| Notiser för nya spel | A och B Tier · kanal propsbot-tier-ab-8f44db | En notis per nytt spel i nivån (rubrik "A TIER …" / "B TIER …") i en egen ntfy-kanal (tier_ntfy_topic). C ger aldrig notis. Övriga notiser (nyheter, uppgraderingar) går till den vanliga kanalen. |
| Livenotiser (Mina spel) | propsbot-live-28c022 | Plingarna under match för dina spel (mål, straff, rött kort, returer, poäng, vunnet/förlorat) i en egen kanal (live_ntfy_topic), så att den kan ha ett eget ljud i ntfy-appen. |
| Insats (A/B) | 15–45 kr, ¼ Kelly-skalad (28/11) | Ersätter flata 1–3u. ¼ Kelly (tak 2 % av kassan) skalas linjärt 15→45 kr. Taket är 45 kr bara vid gamla maxbet-villkoret (edge 100 %–20 % [`tier_3u_edge`/`tier_3u_max_edge`], Pinnacle som referens, sharp money med oss) – just nu satt så maxbet aldrig triggas (`tier_3u_edge`=1.0), så i praktiken 15–30 kr. Annars 30 kr-tak. `units` (bokföring/Sheet) = kr / (kassa × 1 %). |
| Kelly-styrd insats (A/B/C) | ¼ Kelly, tak 2 % | `kelly_pct`/`kelly_u` räknas per spel och styr nu insatsen (stake_kr) direkt, inte bara skugga. Jämförs i tools/quant_report.py (docs/PLAN.md fas 6). |
| Parlayer | 2–4 ben, 10–20 kr insats, edge ≥ 8 % | Kombinerar redan godkända A/B-spel (valfri sport, 28/11) från OLIKA matcher till en parlay. Egen, lägre kr-skala (`parlay_stake_min_kr`/`parlay_stake_max_kr`) än enskilda ben eftersom sammansatt risk är högre - inget maxbet-undantag. combo_odds antas vara produkten av bendes egna odds (overifierat mot Paf). Syns i egen Sheet-flik + `site/csv/parlayer.csv`. |
| Tak (A/B) | inga | Inga dags- eller matchbudgetar (18/11): du väljer själv vilka spel du tar. Alla A- och B-spel räknas som spelade. |
| Odds Alert (oddsvakt) | på, läsning var 30 s, 2 läsningar i rad, högst en notis per spel och 10 min | Bevakar Kambi-oddset för A/B-spelen som fått notis (och dina egna bevakningar från webbsidan) fram till start. ✅ BACK UP när oddset är tillbaka på lägsta oddset, ❌ GONE när det fallit under eller spelet är borta. Lägsta odds = max(spela från, odds som ger kravet på edge mot den senaste skarpa sannolikheten). Spel du tagit bevakas inte. Egen Telegram-chatt telegram_chats.oddsvakt (satt). |
| Spelbara bolag | paf | Unibet limiterat (28/11). Svenskaspel/ATG pausade (Apple Pay-strul) – bara Paf spelbart tills vidare. Läses ändå alla (unibet, betmgm, expekt, leovegas, svenskaspel, atg m.fl.) bara för att mäta marginalen/konsensus. |
| Fotboll | på igen (28/11) | Stängdes av kort för att fokusera på NBA/Paf, slogs på igen samma dag. `use_kambi`, `sides_enabled`, `fouls_enabled`, `sides_extra_leagues` = true. |
| Minsta edge (alla spel) | 6 % | edge = sannolikhet × odds − 1. Gäller alla marknader och sporter. |
| Oddsram | 1,40–6,00 | Inga spel utanför. |
| Max oddsfall | 3 % | Inget spel om bästa oddset fallit mer än så från det högsta vi sett (för sent). |
| Sharp money mot oss | 2 procentenheter | Inget spel om den skarpa referensen (Pinnacle/konsensus) rört sig så mycket mot oss efter 30 min. |
| Sharp money med oss | 1.5 procentenheter | Markeras i notisen (⬆). |
| Topp 5 som notis | nej (14/11) | Topp 5 är alltid LIVE-spel som redan fått en LIVE-notis, så en egen topp 5-notis blev en dubblett. Listan finns kvar i fliken Topp 5. |
| Lagnyheter (varje skanning) | NBA: ESPN skadelista · fotboll: startelvan | Out/doubtful, ute eller inte i laget/startelvan = inget spel; questionable markeras. Öppna LIVE-spel kontrolleras igen före start och ger en notis (📰) om spelarens status ändras – och i NBA även när en lagkamrat (minst 15 min/match) blir out efter att spelet lades, med modellens nya speltid, väntat värde och edge vid vårt odds. |
| Orimlig edge | 25 % | Större edge = nästan alltid fel linje, olika regler eller spelaren spelar inte. Inte spelbart. |
| Ett spel per spelare och match | ja, över allt | Över alla marknader, linjer, sidor (över/under), bolag och körningar. Störst edge vinner; det som redan skickats står kvar. |
| Över eller under | den sida som har EV+ | Båda sidor prövas på samma krav. Under kräver en tvåsidig eller skarp referens (annars är marginalen på undersidan okänd). |
| Notiser | nya spel i A/B Tier | En notis per spel, aldrig två på samma spelare i samma match. Misslyckad notis skickas igen nästa körning (före start). |
| Unit (data/LIVE-bokföringen) | 1u = 0,2 % av bankrullen, 1–10u efter styrkan | LIVE-insatsen följer styrkan (samma tal som Topp 5: edge upp till 15 + halva modellens edge + sharp money + 1). Styrka ≤ 7 = 1u, 9,5 = 3u, 11 = 4u, 14 = 6u, 17 = 8u, ≥ 20 = 10u. 10u (2 %) = maxinsats, ett av de starkaste spelen. Radarn visar samma skala. Data- och skuggbokföringen behåller ¼ Kelly (taket 10u). |
| Skuggspel | ≥ 2 % edge, stoppat av en regel | Bokförs och rättas för att se om reglerna kostar eller sparar pengar. Ingen notis. |

| Benlogg (alla ben) | på, testläge | Varje fotbollsben med modell och BEKRÄFTAD startspelare loggas före avspark (bokforing_ben_alla.json, ögonblicksbild som uppdateras fram till avspark), rättas mot ESPN och flyttas kompakt till benlogg_avgjorda.json.
