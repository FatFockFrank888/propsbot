Fotboll Prop-radarn

Skott, skott på mål, mål och assist per spelare hos Kambi-bolagen. Sannolikheten är Kambis rättvisa pris justerat mot Pinnacles matchlinjer och gäller givet att spelaren spelar (annars stryks spelet). Spelbart från 2 % edge (4 % för mål och assist, +3 procentenheter vid ensidigt pris), odds 1,40–6,00. "Spela från" = lägsta odds som räcker. Insats = föreslagen andel av bankrullen efter EV (¼ Kelly, högst 2 % per spel och 5 % per match). Grön = spelbar, grå = positivt EV men under edgekravet, 0 % = negativt EV.
Visar bara ben med minst 2 % edge. Grön = spelbar (uppfyller marknadens edgekrav).
